当前开发版本：`1.0.0rc3.dev1`。这是源代码功能推进，不是新增完整成品发行。

## 已实测的范围

2026-09-16 21:17（UTC+08:00），在已经处于前台、已登录的 TIM 客户端中，通过 `collect --allow-ui` 完成消息管理器打开、精确目标群核对、右键导出菜单识别、原生保存对话框填写、TXT 格式选择、文件完成检测、解析、ChatLab 导入与物理回读。一次约 15.8 秒，4,657 条，重复导入新增 0 条。原生获取时间来自每次 acquisition.captured_at；同一内容批次重放保留最初 source_observed_at，不用新导出时间伪装旧消息发生时间。

实现使用已校准且带 SHA256 的本机图像锚点和标准原生保存控件，不用 LLM 或 OCR。像素匹配必须唯一且达到固定置信阈值，缺失/歧义时报错，不以旧坐标盲点。进程身份、前景、按键占用、用户输入及源文件校验继续生效，软件版本只作诊断。

`visual-anchors-v1` 当前仅支持 TIM，并明确要求开始时目标客户端在前台。它不能被称为跨客户端全自动前景编排。锚点需要在本机实际界面校准；界面缩放、主题或布局不匹配时应重新核对，不降低阈值或放开会话边界。校准图片和真实来源配置只保存在私有 `.local/`，不进入 Git。

## CLI

开发环境安装可选依赖：

```powershell
python -m pip install -e '.[windows,visual,crypto]'
im-hub --home '<私有数据目录>' collect --config '<私有来源配置>' --source '<TIM来源名>' --allow-ui
im-hub --home '<私有数据目录>' query --platform qq --limit 50
```

本机接续配置中已经存在经过实测的 TIM 来源，不需要重新覆盖配置。`transport=tim-ui`、`adapter=tim-sequence-json`，`desktop.strategy=visual-anchors-v1`。各图像锚点对应已核对群名、消息记录按钮、消息管理器、群列表、导出菜单；标准保存对话框独立验证默认文件名和 TXT 类型。完整历史严格前缀不匹配仍停止，不能用正文 hash 强行吞并真实同文消息。
